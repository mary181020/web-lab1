## 📐 Брейкпоїнти та адаптивність
* **Мобільний (<768px):** Базовий макет (Mobile First), вертикальна колонка, меню стовпчиком.
* **Планшет (768px — 1199px):** З'являється фіксована `sticky`-шапка, меню стає горизонтальним, сітки карток адаптуються під кілька колонок.
* **Десктоп (≥1200px):** Контейнер вирівнюється по центру з фіксованою максимальною шириною, розширені відступи для великих екранів.
